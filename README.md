# [Project 01] Simulating Syntactic Bottlenecks & Predictive Coding
# Predictive_Coding_SOV_vs_SVO
Python simulation of LLM surprisal and cognitive load in cross-linguistic naturalistic reading, focusing on the syntactic bottlenecks between English (SVO) and Korean (SOV).


### About This Project

This project is the computational manifestation of my core research hypothesis. The paradigm of language processing is rapidly shifting toward real-time tracking of naturalistic narratives. However, the Anglocentric focus on SVO (Subject-Verb-Object) structures creates a critical blind spot regarding the 'syntactic cognitive load' in SOV languages (like Korean). 

**Hypothesis:** The head-final structure of SOV languages forces a **'delayed semantic commitment'**, expanding the working memory buffer. Consequently, when the verb finally appears at the end of the sentence, it triggers a massive resolution of syntactic surprisal, which will be reflected in a sharp spike in cognitive load (simulated here as LLM Surprisal / N400 amplitude) compared to the more evenly distributed load in SVO languages.

### Methodological Note: A Priori Computational Simulation

Please note that the data visualised in this repository is **synthetically simulated (a priori generative modeling)** rather than empirically collected neuroimaging data. 

In modern computational neuroscience, simulating expected neurophysiological trajectories before actual data acquisition is standard practice. The primary objectives of this simulation are:
1. **Mathematical Formalization:** To translate a theoretical linguistic hypothesis (delayed semantic commitment in SOV structures) into an explicit, quantitative predictive model.
2. **Pipeline Feasibility:** To demonstrate programmatic readiness to execute time-series visualizations and statistical models immediately upon gaining access to real-world MEG/fMRI datasets.

### Theoretical Foundations & References

This simulation is grounded in the following core literature:
* **Gibson, E. (1998).** Linguistic complexity: locality of syntactic dependencies. *Cognition*, 68(1), 1-76. *(Theoretical basis for Dependency Locality Theory and working memory load in head-final SOV structures)*
* **Kwon, N., Polinsky, M., & Kluender, R. (2013).** Subject/object processing asymmetries in Korean relative clauses: Evidence from ERP data. *Language and Cognitive Processes*, 28(10), 1379-1408. *(Empirical ERP evidence of syntactic processing bottlenecks and P600/N400 delays in Korean)*
* **Levy, R. (2008).** Expectation-based syntactic comprehension. *Cognition*, 106(3), 1126-1177. *(Mathematical foundation for quantifying syntactic surprisal as logarithmic predictive processing error)*
* **Huth, A. G., de Heer, W. A., Griffiths, T. L., Theunissen, F. E., & Gallant, J. L. (2016).** Natural speech reveals the semantic maps that tile human cerebral cortex. *Nature*, 532(7600), 453-458. *(Methodological anchor for naturalistic narrative processing)*
